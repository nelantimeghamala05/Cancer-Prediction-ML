# Cancer Prediction Using Machine Learning
## Overview
This project predicts whether a tumor is Benign or Malignant using Machine Learning classification techniques.
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Data Exploration
4. Model Training
5. Prediction
6. Model Evaluation
## Results
The model achieved approximately 96% accuracy in predicting cancer diagnosis.
